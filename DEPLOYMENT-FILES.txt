🚀 WORKFLOW DE DEPLOYMENT:

1. DESCARGA los 4 archivos principales
2. COPIA a tu carpeta sin-city-fest/
3. EJECUTA en terminal:

   $ cd sin-city-fest
   $ git add .
   $ git commit -m "Deploy: Sin City Fest with Vercel + Supabase"
   $ git push origin main

4. VERCEL DETECTA AUTOMÁTICAMENTE y hace deployment
5. Tu URL estará en: https://sin-city-fest.vercel.app
